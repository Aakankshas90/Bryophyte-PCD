# Bryophyte-PCD

## Objective
Study programmed cell death (PCD) in bryophytes using available transcriptomic datasets.

## Organisms
- *Physcomitrium patens*
- *Marchantia polymorpha*
- *Arabidopsis thaliana*

## Planned Workflow for bryophytes
- RNA-seq preprocessing
- QC
- alignment
- quantification
- differential expression
- pathway enrichment
- ML-based classification

## Tools
- Nextflow
- Docker
- Python
- R
- GitHub
